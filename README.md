# Jejak Berpikir — Prototype antarmuka

Prototype statis berbasis HTML, CSS, JavaScript, dan Bootstrap 5. Tidak menggunakan database atau backend.

## Menjalankan

1. Ekstrak ZIP.
2. Buka folder `jejak-berpikir` di Visual Studio Code.
3. Jalankan `index.html` dengan ekstensi Live Server.
4. Pilih Masuk, isi nama, lalu pilih peran Siswa atau Guru.

## Isi prototype

- Landing page
- Simulasi pemilihan peran
- Dashboard siswa dan guru dengan gaya berbeda
- Pos Jejak, Jeda, dan Uji Mikro
- Pemandu refleksi berbasis pertanyaan pancingan
- Data guru ilustratif dan detail siswa
- Tampilan responsif untuk laptop dan HP

## Catatan

Seluruh data dan interaksi bersifat simulasi di browser. Tidak ada autentikasi sungguhan, sinkronisasi antarperangkat, atau penyimpanan ke server. Untuk kebutuhan esai, prototype ini memperlihatkan rancangan alur dan antarmuka; bukan bukti hasil uji coba atau efektivitas sistem.
